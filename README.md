# Pena Alien Bot

Telegram-бот на aiogram 3, который отслеживает сообщения с ошибочной раскладкой или случайный набор символов и реагирует на них случайной гифкой.

## Как устроен

- Отсекает нормальный английский текст через C-модуль (`mmap` + бинарный поиск по отсортированному словарю). Если C-модуль не скомпилирован, автоматически переключается на Python (`pyspellchecker`).
- Переводит раскладку QWERTY -> ЙЦУКЕН и проверяет наличие осмысленных русских слов.
- При срабатывании отправляет GIF, кэшируя Telegram `file_id` первого сообщения, чтобы не перезаливать файлы с диска.

## Необходимые файлы

1. `my_dict.txt` в корне — отсортированный по алфавиту словарь английских слов (разделитель строк LF, кодировка UTF-8).
2. `gifs/` — папка с файлами `.gif` в корне проекта.
